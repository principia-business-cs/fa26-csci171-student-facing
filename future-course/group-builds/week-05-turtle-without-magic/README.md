# Week 05 Group Build: Turtle Without Magic

## Goal

Create a turtle drawing and explain what each repeated movement does. The drawing matters, but the explanation matters just as much.

## Textbook Connection

- Chapter 3: Hello, little turtles!
- Chapter 7: Iteration
- Textbook turtle chapter: <https://openbookproject.net/thinkcs/python/english3e/hello_little_turtles.html>

## Build Requirements

- [ ] Use a `for` loop with `range()`.
- [ ] Draw at least one repeated shape.
- [ ] Use `forward()` and a turn command such as `left()` or `right()`.
- [ ] Use at least two turtle style commands such as `pencolor()`, `fillcolor()`, `pensize()`, or `speed()`.
- [ ] Use `penup()`, `pendown()`, or `goto()` to move without drawing at least once.
- [ ] Add comments explaining the loop and the shape it creates.

## Reflection Prompt

In Canvas, submit 3-5 sentences: What part of the drawing is controlled by the loop?

## Rubric

| Area | Points | Evidence |
|---|---:|---|
| Loop use | 3 | Uses `for` and `range()` correctly |
| Turtle commands | 3 | Movement and style commands are used correctly |
| Drawing clarity | 2 | Output is recognizable and intentional |
| Explanation | 2 | Comments/reflection explain the repeated pattern |
