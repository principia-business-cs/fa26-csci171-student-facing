# Week 05 Group Build: Turtle Without Magic

## Goal

Create a turtle drawing and explain which repeated movement comes from the loop.

## Textbook Connection

- Chapter 3 and Chapter 7
- Textbook: <https://openbookproject.net/thinkcs/python/english3e/>

## Build Requirements

- [ ] Use a `for` loop with `range()`.
- [ ] Draw at least one repeated shape.
- [ ] Use movement and turning commands.
- [ ] Use at least two turtle style commands.
- [ ] Use penup/pendown or goto.
- [ ] Add comments explaining the repeated pattern.

## Reflection Prompt

In Canvas, submit 3-5 sentences: What did your group build, what did you personally contribute, and what would you improve with 20 more minutes?
