# Week 04 Group Build: Guessing Game Walkthrough

## Goal

Build and trace a guessing-game loop so everyone can explain what changes each round.

## Textbook Connection

- Chapter 7
- Textbook: <https://openbookproject.net/thinkcs/python/english3e/>

## Build Requirements

- [ ] Use a `while` loop.
- [ ] Use a loop-control variable.
- [ ] Give too low, too high, and correct feedback.
- [ ] Count the guesses.
- [ ] Stop with a clear condition.
- [ ] Add comments or notes tracing two sample guesses.

## Reflection Prompt

In Canvas, submit 3-5 sentences: What did your group build, what did you personally contribute, and what would you improve with 20 more minutes?
