# Week 04 Group Build: Guessing Game Walkthrough

## Goal

Build and explain a guessing-game loop. Your group should be able to trace how the variables change on each turn.

## Textbook Connection

- Chapter 6: Fruitful functions, for careful return-value thinking
- Chapter 7: Iteration
- Textbook iteration chapter: <https://openbookproject.net/thinkcs/python/english3e/iteration.html>

## Build Requirements

- [ ] Use a `while` loop that continues until the correct answer is guessed.
- [ ] Use a sentinel or loop-control variable.
- [ ] Give different feedback for too low, too high, and correct.
- [ ] Count the number of guesses.
- [ ] Stop the loop with a clear condition.
- [ ] Add a trace comment or short table showing what changes after two sample guesses.

## Reflection Prompt

In Canvas, submit 3-5 sentences: What condition keeps the loop running, and what finally stops it?

## Rubric

| Area | Points | Evidence |
|---|---:|---|
| Loop control | 4 | Loop starts, repeats, and stops correctly |
| Conditional feedback | 2 | Low/high/correct branches work |
| Guess counter | 2 | Attempts are counted accurately |
| Trace/reflection | 2 | Group explains variable changes |
