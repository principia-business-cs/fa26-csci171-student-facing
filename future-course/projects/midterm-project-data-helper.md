# Midterm Project: Personal Data Helper

## Placement

Future canonical placement: Weeks 8-9.

## Goal

Build a small command-line program that helps a user organize, calculate, or analyze a small set of information.

## Required Concepts

- input and output
- variables and arithmetic
- conditionals
- loops
- functions
- strings
- lists or tuples

## Requirements I Will Check

- [ ] Program has a clear purpose stated in comments or printed intro.
- [ ] Uses at least three functions.
- [ ] Uses at least one loop and one conditional.
- [ ] Uses a list or tuple to store multiple values.
- [ ] Uses string cleanup or formatting.
- [ ] Includes at least five realistic sample values or lets the user enter them.
- [ ] Prints a useful final summary.
- [ ] `notes.md` explains two tests and one improvement you would make next.

## Rubric

| Area | Points | Evidence |
|---|---:|---|
| Program purpose | 3 | Purpose is clear and useful |
| Concept integration | 5 | Required concepts work together |
| Code organization | 4 | Functions reduce repetition and improve readability |
| Testing/reflection | 3 | Notes show testing and next-step thinking |
