# Mini Project 1: Turtle Sketch And Pattern

## Timing

Future canonical placement: Weeks 5-6.

For the current semester, do not start this project unless your instructor assigns it in Canvas.

## Purpose

This project combines turtle movement, `for` loops, variables, colors, and simple function design. It is adapted from Andy's older Turtle Sketch and Loops Project materials, but written in the clearer course format used now.

## Textbook And Reference Sections

- Official textbook: Chapter 3, Hello, little turtles
- Official textbook: Chapter 7, Iteration
- Python turtle reference: <https://docs.python.org/3/library/turtle.html>
- W3Schools for loops: <https://www.w3schools.com/python/python_for_loops.asp>

## Required Level

- [ ] Draw a recognizable image or pattern using turtle.
- [ ] Use `forward()` or an equivalent movement command.
- [ ] Use `circle()` at least once.
- [ ] Use `begin_fill()` and `end_fill()` at least once.
- [ ] Use at least one `for` loop.
- [ ] Use at least two variables controlling size, color, or repetition.
- [ ] Add comments marking where each required feature first appears.
- [ ] Include a short `notes.md` explaining what the drawing is and what you tested.

## Stretch 1

- [ ] Add `pencolor()` or `fillcolor()`.
- [ ] Use `penup()`, `pendown()`, and `goto()`.
- [ ] Define and call at least one function.

## Stretch 2

- [ ] Define one function that calls another of your functions.
- [ ] Use nested loops or repeated function calls to create a more complex pattern.
- [ ] Add one additional turtle feature from the official turtle documentation.
