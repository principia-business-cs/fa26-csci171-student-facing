# Final Project: Integrated Python Program

## Placement

Future canonical placement: Weeks 14-16.

## Goal

Build a small but complete Python program that solves a problem, supports a workflow, tells an interactive story, analyzes data, or creates an interactive visual experience.

## Required Concepts

- functions
- conditionals
- loops
- at least one collection
- one advanced feature from files, events, modules, or classes

## Requirements I Will Check

- [ ] Program runs from a clear `main()` entry point.
- [ ] Program has a specific user or purpose.
- [ ] Uses functions to organize the program.
- [ ] Uses a loop and a conditional in meaningful ways.
- [ ] Uses a list, tuple, object list, or another collection.
- [ ] Includes one advanced feature: files, events, modules, or classes.
- [ ] Includes comments only where they clarify decisions.
- [ ] Includes a short demo plan in `notes.md`.
- [ ] Includes a reflection on what you changed after feedback.

## Rubric

| Area | Points | Evidence |
|---|---:|---|
| Correctness | 5 | Program runs and handles normal use |
| Integration | 5 | Multiple course concepts work together |
| Design | 4 | Code is organized and readable |
| User experience | 3 | Output/input flow is understandable |
| Reflection/demo | 3 | Demo and reflection show ownership |
