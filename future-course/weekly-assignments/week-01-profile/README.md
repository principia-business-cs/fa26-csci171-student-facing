## Concepts You Need

- `print()` displays information for the user.
- Strings are text values inside quotes.
- Variables give names to values so the program is easier to change.
- Python can do math inside expressions before printing the result.
- Multi-line output can make a simple program feel more intentional.

## Small Example

```python
name = 'Maya'
favorite_number = 7
print('Name: ' + name)
print('Double:', favorite_number * 2)
```
