## Concepts You Need

- A program is a sequence of instructions.
- `print()` displays output.
- Text values are strings and must use matching quotation marks.
- Python runs statements in order from top to bottom.
- Comments start with `#` and help humans understand the code.

## Small Example

```python
print("Hello, CSCI171")
print("I can run Python code.")
print("2 + 3 =", 2 + 3)
```
