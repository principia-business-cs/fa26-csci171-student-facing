# Project 0: GitHub Setup And First Pull Request

## Timing

- Assigned: Week 1
- Due: Week 1, Friday, before the end of class unless Canvas says otherwise
- Branch name: `project-00-github-setup`

## What You Are Building

Set up the workflow you will use all semester: local `CSCI171` folder, GitHub repo, Git authentication, branch, commit, push, and pull request.

## Course Connection

This is a course infrastructure project. It supports every later programming assignment and is graded for completion and accuracy, not programming difficulty.

- Student setup guide: `setup/01-student-setup-guide.md`
- Fresh repo creation: `setup/04-fresh-assignment-repo.md`
