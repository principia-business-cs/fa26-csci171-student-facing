Welcome to CSCI171. This repository contains student-facing course materials for Fall 2026.

## Where To Start

1. Read [the syllabus](./syllabus.md).
2. Review [the course schedule](./schedule.md).
3. Complete [Setup Step 1: GitHub Account](./setup/01-github-account.md).
4. Complete [Setup Step 2: Thonny](./setup/02-thonny.md).
5. Complete [Setup Step 3: Git And Assignments](./setup/03-git-and-assignments.md).

7. Check the current week folder before each class.

## Setup Checklist

Before the first programming assignment, make sure you can say yes to each item:

- I can sign in to GitHub.
- I sent my GitHub username to my instructor.
- I can open the `principia-business-cs` GitHub organization.
- I installed Thonny.
- I can run `print("Hello, CSCI171!")` in Thonny.
- I know where to find my assignment repository link.
- I know how to ask for help with a screenshot or exact error message.

## Weekly Pattern

Monday:

- New topic
- Slides
- Code reading
- Live coding
- Short game, puzzle, or activity

Wednesday:

- Group programming build
- Odd weeks: instructor-assigned groups
- Even weeks: student-chosen groups

Friday:

- Individual in-class programming project
- Short quiz or concept check
- Code submission
