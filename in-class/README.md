# In-Class Practice

This folder is for small programs we write together during class. The goal is practice, not polish.

Use these files to practice:

- defining and calling functions
- passing lists into functions
- looping through lists
- returning values from functions
- searching for values in a list
- improving a search when the list is already sorted

## Simple Programs

Start in [simple-programs](./simple-programs/README.md).

Suggested order:

1. `01_functions_and_lists.py`
2. `02_find_by_checking_items.py`
3. `03_find_by_halving.py`
4. `04_search_reflection.py`

For each file, run it, read the output, then fill in the TODOs.
