# In-Class Practice

This folder is for small programs we write together during class. The goal is practice, not polish.

Use these files to practice:

- defining and calling functions
- passing lists into functions
- looping through lists
- returning values from functions
- searching for values in a list
- improving a search when the list is already sorted

## Fun with Prime Numbers

[Fun with Prime Numbers](fun-with-prime-numbers/README.md): explore what makes a number prime, develop your own prime-checking function, and use it to generate primes. Includes test cases, reflection questions, and optional challenges. Write your own solution without copied or AI-generated code.

## Fun with Prime Numbers — Part 2

[Fun with Prime Numbers — Part 2](fun-with-prime-numbers-part-2/README.md): generate primes by marking multiples in a Boolean list. Includes a worked paper example, implementation requirements, test cases, and reasoning about improvements. Write your own implementation; no starter or solution code is provided.

## Parts Desk: Classes And Objects

Build a [parts inventory manager](parts-manager/README.md) using objects, a list, search, a menu, and input validation. Includes a starter, checkpoints, test cases, and two optional extensions.

## Week 10 Individual Turn-In

[Campus Library Checkout](week-10-library/README.md): build a class-based library with a list of objects, functions, a tuple summary, and an interactive menu. Individual work, 10 points, due by the end of class. No starter file.

## Simple Programs

Start in [simple-programs](./simple-programs/README.md).

1. `01_functions_and_lists.py`
