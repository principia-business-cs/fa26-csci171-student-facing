# Simple In-Class Programs

These are short practice programs for class. They are intentionally small so you can focus on one idea at a time.

## How To Use These

1. Open one file at a time.
2. Read the starter code.
3. Run it before changing anything.
4. Fill in the TODOs.
5. Run it again.
6. Explain out loud what your code is doing.

## What You Are Practicing

- Lists store many values in one variable.
- Functions let us name and reuse a process.
- A loop can inspect values one at a time.
- A sorted list lets us rule out many values faster.

## Class Challenge

By the end, your goal is to write a function that can find a number in a sorted list by repeatedly checking the middle and throwing away the half that cannot contain the answer.

After we build it, we will name that strategy.
