# Setup Step 2: Thonny

Thonny is the first programming tool we will use.

## Do This

1. Download Thonny: https://thonny.org/
2. Install it.
3. Open Thonny.
4. Type this:

```python
print("Hello, CSCI171!")
```

5. Click `Run`.

If Thonny asks you to save the file, save it in a folder named `CSCI171`.

## Done When

You see this output:

```text
Hello, CSCI171!
```
