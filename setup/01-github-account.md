# Setup Step 1: GitHub Account

You will use GitHub to receive and submit programming assignments.

Complete this before the first programming assignment.

## Step 1: Open GitHub

Go to:

https://github.com

Sign in if you already have an account. Create a free account if you do not.

## Step 2: Use A Recognizable Account

Use a GitHub username you are comfortable sharing with your instructor.

Good usernames are simple and recognizable. They do not need to include your full name, but your instructor must be able to match the username to you.

## Step 3: Add Your School Email

In GitHub:

1. Open your profile menu.
2. Go to `Settings`.
3. Go to `Emails`.
4. Add your school email address if it is not already listed.
5. Verify the email address if GitHub asks you to.

## Step 4: Send Your Username

Send your GitHub username using the method your instructor requests.

Do not send your password.

## Step 5: Check That You Can Open The Course Organization

Open:

https://github.com/principia-business-cs

You may not see all course repositories yet. That is normal. Your instructor will add access as assignments are created.

## Success Check

You are done when:

- You can sign in to GitHub.
- You know your GitHub username.
- Your instructor has your GitHub username.
- You can open the `principia-business-cs` organization page.

## If You Get Stuck

Ask for help and include:

- Your GitHub username
- A screenshot of the page or error
- The step number where you got stuck
