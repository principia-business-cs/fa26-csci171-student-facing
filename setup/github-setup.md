# GitHub Setup

You will use GitHub to access and submit programming work.

## Steps

1. Create or sign in to your GitHub account.
2. Send your GitHub username to your instructor.
3. Accept any organization or repository invitation your instructor sends.
4. Use HTTPS clone links unless your instructor says otherwise.

Example:

```powershell
git clone https://github.com/principia-business-cs/fa26-csci171-i01-profile-yourusername.git
```

## Basic Commands

```powershell
git status
git add .
git commit -m "Describe what changed"
git push
```
