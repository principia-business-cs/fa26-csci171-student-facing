# Quiz Expectations

Weekly quizzes are short checks, not traps.

## What To Expect

- about 20 minutes for most students
- 30 minutes max for slower test takers
- mostly auto-graded questions
- vocabulary, code reading, tracing, and debugging

## How To Prepare

You should be able to pass if you:

- attend class
- review the condensed slides or notes
- practice the week's code examples

Reading the textbook helps you do better, especially on code-reading questions.

## Question Types

Quizzes may include:

- multiple choice
- true/false
- matching
- short code-output questions
- debugging questions
