# Week 12 Group Build: File Transformer

## Goal

Read a small text file and transform or summarize it.

## Textbook Connection

- Chapter 13
- Textbook: <https://openbookproject.net/thinkcs/python/english3e/>

## Build Requirements

- [ ] Include a sample input file.
- [ ] Read with a `with open(...)` block.
- [ ] Loop through lines.
- [ ] Create a transformed output or summary.
- [ ] Use string cleanup while processing.
- [ ] Reflection explains one file-handling mistake to avoid.

## Reflection Prompt

In Canvas, submit 3-5 sentences: What did your group build, what did you personally contribute, and what would you improve with 20 more minutes?
