# Week 08 Group Build: Text Analyzer Lab

## Goal

Analyze shared text with string methods, loops, and readable output.

## Textbook Connection

- Chapter 8
- Textbook: <https://openbookproject.net/thinkcs/python/english3e/>

## Build Requirements

- [ ] Use `.lower()` or `.strip()`.
- [ ] Use indexing or slicing.
- [ ] Count at least two text features.
- [ ] Use a loop over characters or words.
- [ ] Print a labeled summary.
- [ ] Reflection explains one string method in plain language.

## Reflection Prompt

In Canvas, submit 3-5 sentences: What did your group build, what did you personally contribute, and what would you improve with 20 more minutes?
