# Week 10 Group Build: Tuple Records Lab

## Goal

Represent small records with tuples and process them with loops.

## Textbook Connection

- Chapter 9
- Textbook: <https://openbookproject.net/thinkcs/python/english3e/>

## Build Requirements

- [ ] Create at least four tuple records.
- [ ] Unpack tuple values in a loop.
- [ ] Find a best, total, average, or count.
- [ ] Use a condition while processing records.
- [ ] Format output clearly.
- [ ] Reflection explains why these records can be tuples.

## Reflection Prompt

In Canvas, submit 3-5 sentences: What did your group build, what did you personally contribute, and what would you improve with 20 more minutes?
