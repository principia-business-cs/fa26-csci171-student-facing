# How Your Code Is Graded

Clear expectations are part of the course design. Before you submit, compare your work to this guide.

## Individual Coding Projects

Most Friday projects use this 20-point pattern.

| Category | Points | What It Means |
|---|---:|---|
| Program runs | 4 | Your program runs without crashing for normal input. |
| Required features | 6 | Your program does what the assignment asks. |
| Code clarity | 4 | Your names, formatting, and comments make the code readable. |
| Problem solving | 4 | Your solution uses the week's concept in a reasonable way. |
| Submission practice | 2 | You submit the correct files and complete any reflection. |

## What Good Looks Like

Before submitting, check:

- I read the assignment `README.md`.
- My program runs at least twice.
- I tried normal input.
- I tried one unusual input if the assignment asks for it.
- My variable names make sense.
- I removed code that I no longer need.
- I added comments where they help a reader.
- I completed the reflection if one is required.
- I pushed my work to GitHub.
- I refreshed GitHub and confirmed my latest file is there.

## Wednesday Group Builds

Group builds are lower stakes. They are practice for Friday.

| Category | Points | What It Means |
|---|---:|---|
| Participation | 3 | You contribute to discussion, testing, coding, or notes. |
| Collaboration | 3 | Your group shares work and keeps members included. |
| Working attempt | 2 | Your group makes a serious attempt or documents blockers. |
| Reflection/demo | 2 | Your group can explain what changed and what you learned. |

## Extra Credit

Extra credit extends the Friday project. It should not require a brand-new concept that we have not practiced.

Good extra credit usually adds:

- clearer output
- one more feature
- more careful input handling
- a short reflection
- a small creative extension

## Getting Help Before Submitting

Good help requests are specific.

Include:

- What you expected to happen
- What actually happened
- The exact error message
- The part of the code you think is involved
- What you already tried
